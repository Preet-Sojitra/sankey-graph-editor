Drag & drop:
• Drag any node or ribbon to move it. Ribbons touching a node move with it.
• Select a node: green dot = drag out a new ribbon; blue dots = resize.
• Select a ribbon: big dots move each end (they magnet to node edges; hold Alt to disable), squares change width.
• Mouse wheel = zoom at cursor. Drag empty canvas (or hold Space / middle mouse) = pan. Keys: + / − zoom, 0 = fit.
• Arrows nudge (Shift = 10), Ctrl+D duplicate, Del delete, Ctrl+Z / Ctrl+Y undo / redo.
